# Task 2 – Responsive Layouts (Watch.it)

## Introduction

For this task, I created a responsive movie website called Watch.it using HTML and CSS. The main aim was to follow the provided wireframes and make sure the website displayed correctly on desktop, tablet and mobile screens.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## What I Did

I started by creating the HTML structure for the website, including the navigation bar and movie cards. I then used CSS to style the page, add images and organise the content.

I used CSS Grid and Flexbox to arrange the movie cards and keep the layout organised. I also added media queries to change the layout depending on the screen size.

## Testing

After completing the website, I tested it using Chrome Developer Tools at different screen widths. I checked that the movie cards, images, text and navigation displayed properly on mobile, tablet and desktop screens.

I also made some adjustments to the spacing and layout to improve the overall appearance.

## Reflection

This task helped me understand responsive web design better. At first, I found it challenging to make the same website work on different screen sizes. However, by testing the layout and making small changes to the CSS, I was able to improve it.

I also gained more confidence in using CSS Grid, Flexbox and media queries. Overall, this task gave me more practical experience in creating websites that adapt to different devices.
