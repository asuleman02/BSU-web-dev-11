# Erased Tapes – React Blog Layout

## Project Overview

This project is a React website created for Clone Task 1: Layout in React. The aim was to recreate a blog post about Erased Tapes Records using the provided desktop wireframe and written specification.

## Technologies Used

- React
- Vite
- HTML (JSX)
- CSS
- Google Fonts: Protest Guerrilla and Josefin Sans

## Features

- Responsive desktop, tablet and mobile layouts
- Header with logo and navigation links
- Three-column article layout on desktop
- Responsive album artwork gallery
- Author section with profile photo and social media icons
- Comments section
- Footer with navigation and social media icons

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run `npm install` to install dependencies.
4. Run `npm run dev` to start the development server.
5. Open the localhost address displayed in the terminal.

## Testing

The website was visually checked at desktop, tablet and mobile screen sizes. The project was also tested using `npm run build`, which completed successfully.

## Reflection

This task helped me improve my understanding of React components, JSX, CSS Grid, Flexbox and responsive web design. I learned how to organise a webpage into different sections and adjust layouts for different screen sizes. I also practised following a supplied wireframe and using CSS to match specific design requirements.
