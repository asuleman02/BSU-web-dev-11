# Task 1 – Layout in React (Erased Tapes)

## Introduction

For this task, I recreated a blog page based on the Erased Tapes design using React and CSS. The main aim was to follow the provided layout and make the website look as close as possible to the original design.

## Technologies Used

- React
- HTML and CSS
- JavaScript
- Vite
- CSS Grid and Flexbox

## What I Did

I started by setting up the React project using Vite. After that, I worked on the different sections of the page, including the header, music albums, author information, comments section and footer.

I used CSS Grid to arrange the content into three columns and Flexbox to help with alignment and spacing. I also worked on the images, text sizes and colours to match the provided design.

## Testing

After completing the page, I ran the project locally and checked how it looked in the browser. I made adjustments to the spacing, images and layout where needed.

I also checked that the different sections displayed correctly and that the project could build successfully.

## Reflection

This task helped me improve my understanding of React and how CSS can be used to create more complex page layouts.

One of the challenges was getting the spacing and alignment right, especially when working with the three-column layout. I had to make several small changes and check the results in the browser.

Overall, I gained more confidence in using React components and organising a webpage to match a given design.

## How to Run the Project

1. Open the `task-1-layout-in-react` folder in Visual Studio Code.
2. Open the terminal.
3. Run `npm install` to install the required dependencies.
4. Run `npm run dev` to start the development server.
5. Open the local URL shown in the terminal to view the website.
